# Agent 记忆方案调研方法

**状态：Active**
**更新时间：2026-09-01**

本仓库把“可追溯、可比较、可更新”作为调研产出的最低标准。

## 研究步骤

1. 明确问题、受众、范围和非目标。
2. 优先阅读第一方材料：论文、官方文档、公开源码、版本说明和公开 API 文档。
3. 为每个外部项目记录访问日期，以及适用的版本、分支、tag 或 commit。
4. 分离已核验事实、基于事实的推断和面向方案的建议。
5. 将新结论接入现有主题、项目参考和设计文档；不覆盖历史快照。

## 证据状态

| 状态 | 含义 |
| -- | -- |
| Active | 当前仍用于研究、设计或比较的材料。 |
| Snapshot | 针对特定来源、日期或版本的静态观察；不代表来源当前状态。 |
| Historical | 已结束项目或实验的过程记录，只供追溯。 |

## 写作约定

- 默认中文；产品名、API、路径和必要技术术语保留英文。
- 用 **Fact**、**Inference**、**Recommendation** 明确结论性质。
- 不把厂商自报指标、旧版本行为或单次实验结果外推为通用事实。
- 新报告以 [报告模板](../templates/research-report-template.md) 为起点，并从 [文档索引](../README.md) 接入。
